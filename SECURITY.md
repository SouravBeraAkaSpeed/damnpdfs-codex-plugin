# Security

Do not put real documents, authentication material, pairing codes or exploit details in public issues. Report suspected vulnerabilities through https://damnpdfs.com/contact and include only non-sensitive reproduction steps.

The bridge uses an in-memory credential scoped to one approved browser workspace, a fixed HTTPS service origin, bounded response sizes, cancellation signals and exclusive output creation. Review the source before installation. It cannot keep a browser alive or make a revoked credential work. Dependency-free runtime; no installation hooks or startup file transfers.
