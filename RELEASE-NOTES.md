# DamnPDFs for Codex 1.0.0

- 71 PDF, Office, image and audio task tools through a user-approved browser workspace.
- Five connection/catalog/local-file helpers and eight workspace commands.
- Session credentials held in memory, with no API key or account-file access.
- Exact file imports, authenticated downloads and exclusive output creation.
- Light/dark icons, setup skill, practical task guidance and website/help/privacy/terms links.
- 14 automated tests, standard MCP SDK startup, actual installed-package verification and a passing representative live browser/cloud file workflow.

Install through **Plugins → Add → Add a marketplace** with `SouravBeraAkaSpeed/damnpdfs-codex-plugin`, or download this release's ZIP and choose **Upload plugin archive**. Requires Node.js 22+ and a connected DamnPDFs browser tab.

Visit https://damnpdfs.com/ for the tools and https://damnpdfs.com/privacy for processing and retention details. Public Git-backed marketplace distribution is available; default curated Public-directory inclusion is a separate process.
